# CDOC2 Gatling tests

Contains [gatling](https://gatling.io/) tests (basic functional and load tests) for 
[CDOC2](https://open-eid.github.io/CDOC2/) servers. Covers:

* [cdoc2-capsule-server](https://github.com/open-eid/cdoc2-capsule-server) - see [cdoc2-capsule-server/README.md](cdoc2-capsule-server/README.md)
* [cdoc2-shares-server](https://github.com/open-eid/cdoc2-shares-server/) - see [cdoc2-shares-server/README.md](cdoc2-shares-server/README.md)
* [cdoc2-auth-server](https://github.com/open-eid/cdoc2-auth-server/) - see [cdoc2-auth-server/README.md](cdoc2-auth-server/README.md)
* [cdoc2-rp-server](https://github.com/open-eid/cdoc2-rp-server/) - see [cdoc2-rp-server/README.md](cdoc2-rp-server/README.md)

Also includes [mock-sid-mid-server](mock-sid-mid-server/README.md), a mock Smart-ID/Mobile-ID
server for load testing cdoc2-auth-server without depending on the real SK demo environment.
